# What's new in the jar

## Spring release

- **Rename a habit.** New `pebble rename ID NEWNAME`. Changed your mind about what to call it? No need to start a new jar.
- **Longer names.** Habit names can now be up to 80 characters, up from 60.
- **Goodbye, version 1.** `pebble import` no longer reads version 1 export files. If you still have one, export again from an older build first.

Everything else works the way it did.
